# MY Offline Tracker + GS1 Scanner

First page: GS1 scanner ledger.
Second page onward: KPI tracker, sales entry, history calendar, rota, calculator, camera upload.

Privacy:
- Device-only localStorage.
- No external API.
- No cloud upload.
- Service worker only caches local files.
- Camera stream is used only inside the browser page and not transmitted.

Files included for GitHub deploy:
- index.html
- styles.css
- app.js
- manifest.json
- sw.js
- icon-192.png
- icon-512.png
